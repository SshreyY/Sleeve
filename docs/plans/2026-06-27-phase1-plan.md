## Step 2: The Deterministic Paycheck Allocation Engine
Write the mathematically sound paycheck division logic in standard, auditable Python code.

### Tasks
- [ ] Create `backend/app/services/allocation.py`.
- [ ] Implement `generate_allocation_plan(db, paycheck, settings)` containing the exact prioritizing algorithm.
- [ ] Implement `approve_plan(plan_id)` to produce actionable checklists.
- [ ] Implement `complete_plan(plan_id)` to auto-increment Goal balances.

### How to Test Run
1. Create a script `backend/test_engine.py` to register a dummy paycheck and run allocations:
   ```python
   from app.database import SessionLocal
   from app.models import Paycheck, UserSettings, Goal, GoalTypeEnum
   from app.services.allocation import generate_allocation_plan
   
   db = SessionLocal()
   # Setup dummy settings
   settings = db.query(UserSettings).first() or UserSettings()
   # Setup dummy goals
   hysa = db.query(Goal).filter(Goal.type == GoalTypeEnum.emergency_fund).first() or Goal(name="HYSA EF", type=GoalTypeEnum.emergency_fund, current_amount=10000.00)
   db.add(hysa)
   db.commit()
   
   paycheck = Paycheck(gross_pay=4500.00, net_deposit=3050.00, taxes_withheld=900.00, contribution_401k=450.00)
   plan = generate_allocation_plan(db, paycheck, settings)
   print("Planned Total Savings Rate:", plan.total_savings_rate)
   for item in plan.items:
       print(f"  {item.label}: ${item.amount}")
   db.close()
   ```
2. Run it:
   ```powershell
   python backend/test_engine.py
   ```
3. Verify that the sum of the allocations matches your net deposit ($3,050) perfectly and the savings rates are mathematically sound.

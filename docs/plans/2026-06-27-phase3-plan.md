# Step-by-Step Implementation Plan: Phase 3 (The AI Learning Layer)

- **Status:** DESIGN / FUTURE ROADMAP
- **Product:** Sleeve
- **Stack:** LangChain `deepagents` + LangGraph state persistence + PostgreSQL `learned_preferences`

---

## 1. Context and Flow
In Phase 3, we teach the agent to analyze user adjustments and suggest personalized rules (e.g., *"Since you decreased your brokerage allocation twice when travel goals were active, should I prioritize short-term savings over brokerage by default?"*).

We use **LangGraph's state persistence** to evaluate the delta between what our deterministic algorithm *proposed* and what the user *actually saved*.

---

## 2. Step-by-Step Tasks

### Step 1: Create the Override Log System
- **File:** `backend/app/services/allocation.py`
- **Behavior:** When an allocation is modified, log the edit action:
  - `original_amount` vs `final_amount`
  - `category` and active goals
- **Validation:** Verify that edits are saved cleanly in the DB.

### Step 2: Implement the Preference Detection Agent
- **File:** `backend/app/services/ai.py`
- **Behavior:** Create a background service that queries past edits when a new paycheck is registered.
- **Prompt:**
  - Feed the last 3 override logs into Gemini.
  - Ask Gemini: *"Is there a consistent financial preference here? If yes, output a structured JSON preference rule (e.g., priority_adjustment)."*

### Step 3: Implement preference approval UI
- **File:** `frontend/src/components/ChatInterface.tsx`
- **Behavior:** Intercept `<preference-suggestion>` cards. Show a button: `"Apply this preference to future paychecks"`.
- **Validation:** Clicking the button calls `POST /api/preferences/{id}/activate` to set `is_active = True`.

---

## 3. How to Test Run
1. Enter a paycheck via chat.
2. Edit the allocation table: reduce brokerage from $250 to $0, and increase your "Europe Trip" goal from $100 to $350.
3. Save the plan. Repeat this override behavior on a second mock paycheck.
4. On the third paycheck, verify that the chat streams: *"I noticed you like to prioritize your Europe Trip goal. Would you like me to make this a default preference?"* and displays the approval card.
5. Click "Apply", and verify that the next paycheck allocation places the travel goal ahead of the brokerage automatically.

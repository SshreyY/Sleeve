# Step-by-Step Implementation Plan: Phase 4 (Paystub PDF Upload & Parsing)

- **Status:** DESIGN / FUTURE ROADMAP
- **Product:** Sleeve
- **Stack:** Python PDF Parsers (e.g., `pypdf` or `pdfplumber`) + Gemini Multimodal API

---

## 1. Context and Flow
The user uploads a paystub PDF. We send the PDF bytes to Gemini 3.5 Flash, which extracts the financial fields (Gross, Net, Tax withholding, 401k, HSA) with 100% precision. 

The agent displays the parsed figures for user verification before passing them to our deterministic database service.

---

## 2. Step-by-Step Tasks

### Step 1: Install Python PDF Parsers
- Add `pypdf` or `pdfplumber` to `backend/requirements.txt`.
- Activate virtual environment and run `pip install -r requirements.txt`.

### Step 2: Create PDF Upload Route
- **File:** `backend/app/routers/paychecks.py`
- **Behavior:** Add `POST /api/paychecks/upload` endpoint accepting form-data files.
- **Validation:** Return error if file extension is not `.pdf`.

### Step 3: Implement Gemini Extraction Service
- **File:** `backend/app/services/ai.py`
- **Behavior:**
  - Read PDF text contents.
  - Pass the file text + structured schemas to Gemini.
  - Ask Gemini to return a rigid JSON response containing the paycheck fields:
    ```json
    {
      "gross_pay": 4500.00,
      "net_deposit": 3050.00,
      "taxes_withheld": 900.00,
      "contribution_401k": 450.00
    }
    ```

### Step 4: UI Drag-and-Drop upload
- **File:** `frontend/src/components/ChatInterface.tsx`
- **Behavior:** Add a paperclip file upload button to the chat bar. 
- **Validation:** On drop, call the upload endpoint, intercept the parsed response, and display it as an editable form card for the user to confirm.

---

## 3. How to Test Run
1. Place a sample paystub PDF in `backend/tests/fixtures/sample_paystub.pdf`.
2. Open the UI, click the paperclip icon, and upload the PDF.
3. Confirm that the chat shows: *"I've parsed your paystub from Acme Corp! Here is what I found:"* along with a table populated with the exact figures extracted from the document.
4. Click "Generate Plan" and confirm the allocation engine processes it correctly.

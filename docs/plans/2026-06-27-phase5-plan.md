# Step-by-Step Implementation Plan: Phase 5 (Account Tracking & Plaid Integrations)

- **Status:** DESIGN / FUTURE ROADMAP
- **Product:** Sleeve
- **Stack:** Plaid Link Python SDK + Plaid React Link

---

## 1. Context and Flow
To transition Sleeve from manual balance entry to real-time sync, we configure Plaid. This allows the app to automatically detect paycheck deposits into checking, read high-yield savings (HYSA) balances, and update goal progress rings dynamically.

---

## 2. Step-by-Step Tasks

### Step 1: Plaid Credentials & Client Setup
- Sign up for a Plaid developer account and grab your credentials.
- Add `PLAID_CLIENT_ID`, `PLAID_SECRET`, and `PLAID_ENV=sandbox` to your `.env.local` file.
- Add `plaid-python` to `backend/requirements.txt` and run `pip install`.

### Step 2: Implement Plaid Link Endpoints
- **File:** `backend/app/routers/plaid.py`
- **Endpoints:**
  - `POST /api/plaid/create_link_token` -> Returns a session token.
  - `POST /api/plaid/exchange_public_token` -> Exchanges client public token for a secure `access_token` and saves it.

### Step 3: Integrate Plaid Link inside Settings
- **File:** `frontend/src/components/SettingsModal.tsx`
- **Behavior:** Load React Plaid Link. Render a button: `"Connect Bank Accounts (Plaid)"`.
- **Validation:** On success, dispatch token back to backend.

### Step 4: Real-time Balance Sync Services
- **File:** `backend/app/services/goal.py`
- **Behavior:** Create a worker function that pulls account balances from linked Plaid items and automatically updates `Goal.current_amount` for HYSA or Brokerage items.

---

## 3. How to Test Run
1. Open Settings, click "Connect Bank Accounts".
2. Link accounts using Plaid's sandbox credentials (`user_good` / `pass_good`).
3. Verify that the linked checking and savings accounts are registered in your PostgreSQL database.
4. Confirm that your dashboard progress charts automatically sync to the real-time sandbox balances.
